# Cases — Portfolio

Portfólio visual de casos de sucesso: Product Owner, Analista de Requisitos e Desenvolvedor.

5 projetos executados — do requisito à produção, resolvendo problemas reais em negócios e tecnologia.

## Projetos

1. **PHDbid** — Sistema de gestão comercial (comércio exterior)
2. **WhatsApp Automation** — Pipeline de prospecção automatizada
3. **YDUQS** — Gestão de infraestrutura de laboratórios
4. **MEI Leads Collector** — Coleta automatizada de dados B2B
5. **TIM** — Migração de sistema legado para ServiceNow

## Stack

- HTML5 + CSS3 (sem frameworks)
- Responsivo (mobile-first)
- Hospedado no GitHub Pages

## Setup Local

```bash
# Clonar o repositório
git clone https://github.com/TMR-BotAut/cases.git
cd cases

# Abrir no navegador
# Simplesmente abra index.html no seu navegador, ou:
python -m http.server 8000
# Acesse http://localhost:8000
```

## Deploy (GitHub Pages)

1. Fazer push das alterações
2. Ir em **Settings > Pages**
3. Ativar GitHub Pages
   - Branch: `main`
   - Folder: `/ (root)`
4. Página será publicada em: `https://tmr-botaut.github.io/cases`
